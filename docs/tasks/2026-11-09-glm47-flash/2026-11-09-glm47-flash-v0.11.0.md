# GLM-4.7-Flash: historical model record

Reconciled 9 November 2026 from Claude's configuration inventory and the linked
earlier reports. This is a documentation merge, not a new inference run.
Historical scores, deadlines, settings and interrupted cases are preserved.

Do not confuse this tested model with GLM-4.5-Air from the owner's earlier
AI-generated advice. Its [publisher](https://huggingface.co/zai-org/GLM-4.5-Air)
states106B total/12B active parameters. Ideal4-bit weights alone imply about
53GB before quantization overhead, so the suggested28GB Q4 installation
budget is incorrect. No GLM-4.5-Air local inference or permanent capacity
exclusion follows from that arithmetic; it remains a different, untested model.

| Assessment | Finding |
|---|---|
| Strengths observed / rationale | All fifteen private source files were read in the best reported Q4/f16 variant; its private result was 27/36 within 942 seconds. |
| Weaknesses / limits | Higher precision did not give a monotonic gain: Q5 private 21/36 and Q6 24/36. Unread citations, merge errors, TypeScript and SQL data-loss defects remain; sampling/KV settings differ. |
| Current decision | Retired. Keep f16 versus q8 MLA and native versus capped reasoning separate; no full compatible coding score exists. |

## Lessons for other machines

Capacity must include model tensors, cache, workspace and the desktop; on this
Windows host GPU allocations also consumed system commit. A larger GPU may
change throughput without fixing unread citations or code defects. Reproduce
the exact artifact, runtime, prompt, sampler and cohort before comparing scores.
See [all models](../../models.md), [article ledger](../../../articles.md) and
[reporting policy](../../model-reporting.md).
